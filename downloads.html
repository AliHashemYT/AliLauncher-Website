Release status

No public release, alpha prerelease, or tester download has been issued. The historical development package is not a public download. This website does not host Minecraft files, launcher packages, or other game assets.

Target hardware

  • For current tester hardware requirements: a base PlayStation®4 running a jailbroken environment on firmware 11.00. This specific tested development target does not establish compatibility with other devices.
  • A legally owned Minecraft: Java Edition account is required for play and sign-in.
  • Network access is needed for Microsoft authentication and official game/dependency downloads.

These are development targets, not a promise that every installation, peripheral, network or workload will work.

Installation

There are no public installation instructions or package at this time. Do not install files from unofficial mirrors or assume a development build is suitable for use. If an authorized release becomes ready, its supported hardware, verified package, checksum and step-by-step installation guide will be linked from this page.

Version compatibility

  • Minecraft Java 1.8.9: earlier gameplay has been verified on real hardware. Known controller/settings, server-lag and shutdown issues have occurred.
  • Minecraft Java 1.20.1: earlier gameplay and selected modded sessions have been verified on real hardware. The current candidate has not passed fresh-install acceptance.
  • Java 25 / Minecraft 26.3: experimental port work only. Port Check 0.12 passed selected Java/native integration checks; Minecraft 26.3 title and gameplay remain unverified.

Known limitations and release gates

The current alpha readiness record marks a fresh install-and-play release as blocked. A complete clean build, full licensing/source review, authorized Microsoft registration, fresh account/session testing, first-run official game downloads, and a separate fresh-device test remain release gates. Desktop or synthetic checks do not satisfy the physical-device gates.

Never let the launcher switch a world to another game version automatically. Back up saves before using any future alpha. Do not treat the current project as ready for routine gameplay.

Release links

When a real tested release is authorized, this section will link directly to its GitHub release and publish package checksums and scope. Until then, the official source and development records are available from the AliLauncher GitHub repository.
