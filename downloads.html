Target hardware

  • For current tester hardware requirements: a base PlayStation®4 running a jailbroken environment on firmware 11.00. This specific tested development target does not establish compatibility with other devices.
  • A legally owned Minecraft: Java Edition account is required for play and sign-in.
  • Network access is needed for Microsoft authentication and official game/dependency downloads.

These are development targets, not a promise that every installation, peripheral, network or workload will work.

Installation

There are no public installation instructions or package at this time. Do not install files from unofficial mirrors or assume a development build is suitable for use. If an authorized release becomes ready, its supported hardware, verified package, checksum and step-by-step installation guide will be linked from this page.

Version compatibility

  • Minecraft Java 1.8.9: earlier gameplay has been verified on real hardware. Known controller/settings, server-lag and shutdown issues have occurred.
  • Minecraft Java 1.20.1: earlier gameplay and selected modded sessions have been verified on real hardware. The latest C2 comparison failed during JVM initialization, so 1.20.1 with C2 is not verified playable. The current candidate has not passed fresh-install acceptance.
  • Java 17 C2 + Parallel GC: the standalone JVM suite passed physical PS4 testing. This does not establish Minecraft 1.20.1 gameplay under C2.
  • Java 21/25 runtime installation: installation and repair checks are verified on PC only; full PS4 gameplay with these runtimes is not verified.
  • Java 25 / Minecraft 26.3: experimental work only. The latest run reached Vulkan initialization but hit an unresolved VMA allocation-cleanup crash. Minecraft 26.3 is not playable yet.

Known limitations and release gates

The current alpha readiness record marks a fresh install-and-play release as blocked. USB detection still fails even though PS4Xplorer recognizes the drive; in-game media access and transfer are not verified. The Minecraft 1.20.1 C2 JVM-initialization failure and Minecraft 26.3 VMA allocation-cleanup crash also remain unresolved. Dev 2.54 fixes are in development. A complete clean build, full licensing/source review, authorized Microsoft registration, fresh account/session testing, first-run official game downloads, and a separate fresh-device test remain release gates. Desktop or synthetic checks do not satisfy the physical-device gates.

Never let the launcher switch a world to another game version automatically. Back up saves before using any future alpha. Do not treat the current project as ready for routine gameplay.
