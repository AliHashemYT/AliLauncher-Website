Who is responsible

AliHashemYT is the creator and maintainer of the AliLauncher project. For privacy questions about this website or project, use the contact options on the Contact page.

Information collected by this website

This site is designed as static HTML, CSS and JavaScript. It has no account system, contact form, newsletter form, embedded video player, advertising code or analytics script. The local JavaScript controls the mobile navigation, theme toggle, reveal animations and displayed copyright year. If you change the theme, the selected theme is saved in your browser local storage so it persists on later visits. The site does not intentionally send site interaction data or that preference to the project maintainer.

If you choose to follow a YouTube link or visit GitHub, those services receive your request under their own privacy practices. This website does not receive your YouTube or GitHub account credentials.

Hosting, logs and external services

The intended host is GitHub Pages, a service operated by GitHub, Inc. The site has not yet been deployed, so its eventual hosting configuration and log retention have not been independently verified. When hosted, GitHub and its infrastructure may process request data such as IP address, user agent, requested page and timestamp in service/security logs. GitHub determines its own collection and retention practices; consult its Privacy Statement for current information.

The stylesheet uses system fonts and does not request fonts from an external font service. No analytics, tracking pixels, or paid services are included in this source preview. The site does not set cookies in its own code.

GitHub and YouTube links are external. Their services may use cookies or other technologies subject to their own policies and your settings.

Microsoft sign-in and launcher data

The documented launcher account flow sends the user through Microsoft device-code sign-in, then Xbox/XSTS and Minecraft Services to check a Java profile and entitlement. The launcher does not ask the user to give a Microsoft password to AliHashemYT. Microsoft and the other named services process data according to their terms and privacy notices; the application necessarily sends authentication protocol requests to them.

Storage behavior depends on the launcher implementation:

  • The documented portable service layer keeps access, refresh and device tokens in memory and states that signing in is required again after the launcher closes.
  • The preserved native launcher for the tested device documents an optional refresh credential in platform-managed SaveData on the tested device when the mount and round-trip checks succeed. An older encrypted local vault path may require a local unlock password. A memory-only session does not survive process termination. Sign Out clears account state.
  • SaveData/platform storage is not described as a secure enclave and does not protect against privileged code on a jailbroken device. No guarantee is made about persistence or protection on every system.

The exact behavior can vary by revision and configuration. Check the privacy notice shipped with any future authorized download before signing in. Never share passwords, device codes, raw account stores or tokens in support requests. The source states that tokens are excluded from status/progress JSON and redacted from relevant output; this policy does not make a broader security guarantee about all environments.

For installation and downloads, the launcher can contact official Minecraft/Mojang endpoints, Microsoft identity/Xbox/Minecraft Services, Fabric metadata/Maven, and Modrinth services for compatible content, depending on the feature used. These services receive the requests needed to perform the selected operation.

Retention, access and deletion

The static site does not maintain a project-operated user account or analytics database, and no website submission feature is provided. Hosting providers may retain service logs under their own policies. We cannot delete records from GitHub, YouTube, Microsoft, Mojang, Xbox or other third-party systems on your behalf.

Launcher account data is stored locally according to the selected launcher revision and session option; it is not uploaded to this website. Use the launcher’s Sign Out function to clear its saved session where available. Microsoft consent can also be reviewed or revoked through Microsoft’s account controls. For local files, follow the exact version’s documentation and make a backup before removing launcher data; deleting a profile directory may remove its worlds and settings.

Messages voluntarily sent to the creator may be retained in the inbox or platform used to send them until no longer needed, subject to that service’s policies. There is no published fixed deletion period for such messages. Request deletion by contacting the creator through a listed channel, noting that copies may persist in service backups or where law requires retention.
