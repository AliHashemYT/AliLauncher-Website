Vanilla, mods and profiles

The project has documented vanilla and modded profile work. Earlier real-hardware sessions included Fabric and Fabulously Optimized with Controlify. These reports do not establish that every Forge/Fabric mod, loader version, modpack or combination works.

The current service work describes isolated profiles for saves, mods, options and configuration, and Modrinth search/import functions in its application layer. The alpha candidate has not passed complete fresh-install acceptance, so do not assume these management features are ready for public use.

Controls, graphics, audio and networking

Earlier gameplay verified on real hardware includes controller use, AMD graphics, audio, and LAN/multiplayer under tested workloads, plus Java 17 C1 integration. Results vary by workload and are not an exhaustive support matrix. Desktop checks are distinct from real-hardware evidence.

Java 25 / newer Minecraft EXPERIMENTAL

Java 25 and Minecraft 26.3 port work is isolated on an experimental development branch. Port Check 0.12 passed selected Java 25 C1, LWJGL, JNI, SDL, Vulkan and native-presentation checks on tested hardware.

Minecraft 26.3 gameplay is not complete. The game title/gameplay and Java-owned Vulkan draw loop remain unverified. A port-check pass is not a gameplay pass.

What this page does not claim

  • That the current alpha is ready for public installation or distribution.
  • That desktop-only checks establish device functionality.
  • That Minecraft 26.3 gameplay has been completed.
