EARLIER GAMEPLAY · VERIFIED ON REAL HARDWARE

Minecraft Java 1.20.1

Earlier Minecraft Java 1.20.1 gameplay has been verified on real hardware. The latest 1.20.1 C2 comparison failed during JVM initialization and did not reach gameplay; Minecraft 1.20.1 with C2 is not verified playable. First-run installation, download, account and fresh-device acceptance for a public release remain incomplete.

Vanilla, mods and profiles

The project has documented vanilla and modded profile work. Earlier real-hardware sessions included Fabric and Fabulously Optimized with Controlify. These reports do not establish that every Forge/Fabric mod, loader version, modpack or combination works.

The current service work describes isolated profiles for saves, mods, options and configuration, and Modrinth search/import functions in its application layer. The alpha candidate has not passed complete fresh-install acceptance, so do not assume these management features are ready for public use.

Controls, graphics, audio and networking

Earlier gameplay verified on real hardware includes controller use, AMD graphics, audio, and LAN/multiplayer under tested workloads, plus Java 17 C1 integration. Results vary by workload and are not an exhaustive support matrix. Desktop checks are distinct from real-hardware evidence. The isolated Java 17 C2 + Parallel GC suite also passed physical PS4 testing; that standalone JVM result does not verify Minecraft gameplay under C2.

Java 25 / newer Minecraft EXPERIMENTAL

Java 25 and Minecraft 26.3 port work is isolated on an experimental development branch. Port Check 0.12 passed selected Java 25 C1, LWJGL, JNI, SDL, Vulkan and native-presentation checks on tested hardware. Java 21/25 runtime installation and repair checks have PC verification only; they do not establish full PS4 gameplay.

Minecraft 26.3 is not playable yet. The latest run reached Vulkan initialization, then hit an unresolved VMA allocation-cleanup crash. No completed title-screen or gameplay pass is claimed.

Current integration status

USB detection still fails even though PS4Xplorer recognizes the drive. In-game USB media visibility and file transfer are not verified. Dev 2.53 was packaged for private testing; it is not a public release. Dev 2.54 fixes are still being developed.

What this page does not claim

  • That all supported versions, launch flows, controllers, servers, mods or workloads are bug-free.
  • That the current alpha is ready for public installation or distribution.
  • That desktop-only checks establish device functionality.
  • That Minecraft 26.3 gameplay has been completed.
